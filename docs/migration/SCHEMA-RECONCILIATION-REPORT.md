# EduNest Database Schema Reconciliation Report (MySQL 8.0.41 vs PostgreSQL 17.11)

**Task:** EB-82 — MySQL to PostgreSQL Schema & Data Migration  
**Target Public Tables:** 42  
**Legacy Excluded Tables:** 1 (`user_settings`)  
**Encoding:** MySQL `utf8mb4_0900_ai_ci` -> PostgreSQL `UTF8`  
**Temporal Semantics:** All temporal fields use `LocalDateTime` -> PostgreSQL `TIMESTAMP WITHOUT TIME ZONE`  
**Precision Semantics:** Floating point platform profits use `DOUBLE PRECISION`  

---

## 1. Architectural & Type Mapping Overview

| MySQL 8.0 Type | PostgreSQL 17.11 Type | Java / JPA Representation | Conversion & Handling Notes |
| :--- | :--- | :--- | :--- |
| `BIGINT AUTO_INCREMENT` | `BIGINT GENERATED BY DEFAULT AS IDENTITY` | `Long` (`@Id @GeneratedValue`) | Target sequences synced with `setval` after migration |
| `INT AUTO_INCREMENT` | `INTEGER GENERATED BY DEFAULT AS IDENTITY` | `Integer` (`@Id @GeneratedValue`) | Target sequences synced with `setval` after migration |
| `VARCHAR(n)` | `VARCHAR(n)` | `String` | Direct string transfer; UTF-8 verified |
| `TEXT` / `LONGTEXT` | `TEXT` | `String` (`columnDefinition = "TEXT"`) | Direct textual copy; Hibernate 6 `@Lob` removed (no OID) |
| `TINYINT(1)` | `BOOLEAN` | `boolean` / `Boolean` | MySQL `1` -> `TRUE`, `0` -> `FALSE` |
| `DATETIME` | `TIMESTAMP WITHOUT TIME ZONE` | `LocalDateTime` | No timezone offset shifting |
| `DOUBLE` | `DOUBLE PRECISION` | `Double` | Portable IEEE 754 64-bit float |
| `ENUM` | `VARCHAR(255)` | `@Enumerated(EnumType.STRING)` | String representation preserved |
