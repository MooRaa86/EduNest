# Development-only database reset and archive cleanup

This manual procedure applies only to the specific disposable development/demo database approved by the Project Owner. It is not authorized for staging or production. There is no automatic reset or cleanup step and Flyway clean remains disabled.

1. Identify the exact development project, database, connection endpoint and environment in the provider console and independently confirm them with the Owner. Do not rely on a database name or `current_database()` alone. Confirm the target is disposable and that loss of its data and historical recovery records is approved. Stop if identity or authorization is uncertain.
2. Take and verify a backup if any data needs to be retained. Stop writers and prevent the application from connecting during the operation. An authorized operator can rebuild only that confirmed development database using the provider's development reset procedure; no reset is executed by this repository.
3. On the newly empty development database, run the standalone Flyway procedure in `src/main/resources/db/migration/README.md` §3.1.1 and verify successful history through the release's exact version. V3 creates four `public.eb44_archive_*` tables and V10 creates `public.eb51_archive_session_attendance_result` even on an empty database.
4. If removing that development-only clutter is still desired, first independently confirm the five archive tables' counts, dependencies, grants and recovery requirements. Obtain explicit approval for the identified target and any contents; use the provider's manual administrative tools to remove only the five archive tables. Do not remove application tables or modify `public.flyway_schema_history`. Do not perform this step for staging or production.
5. Verify the application and Flyway history against the expected release, and record the target, approvals and outcome without copying sensitive rows or credentials. Future fresh migrations recreate all five tables; any future cleanup requires the same independent checks and approval.
