- Production-chain probes check private, admin and unknown direct access, all four public folders including bytes, traversal-like requests and all four typed routes. Typed tests use actual `FileStorageService` files, H2, JWTs and separate disposable relative and absolute roots; they cover owners, mentors, enrolled and unrelated users, anonymous requests, missing files, paths and Windows directory-junction escapes. Denied calls do not reach the file response builder. The MVC test constructs MockMvc without security filters; production static locations and an unprefixed request are checked.
- Windows directory-junction escape was reproduced before the typed resolver's real-path containment change and denied afterward. This is not proof against a concurrent check/open race; Security/Operations must review upload-tree write permissions and the threat model. Linux absolute/relative roots and ordinary symlinks remain untested in this environment; staging should also verify effective static/proxy configuration.
- The legacy `GET /files?filePath=` handler returns 403 for authenticated requests with the required parameter; anonymous requests are rejected by the production chain. This cross-scope temporary safeguard prevents an ownership bypass but departs from D-06's guard-first default and breaks existing callers. Eng Lead / FE approval is not yet recorded; EB-27 remains open for an ownership-aware replacement. Reverting without a coordinated equivalent would leave private files retrievable by authenticated strangers.
- Admin image URLs are denied, including for authenticated users, and no typed admin-image endpoint exists. The repository documents an authenticated admin profile API; no frontend implementation or documented requirement for anonymous admin images was found. Confirm consumers before release.
- Task student-detail responses lack the submission ID required by the typed task-submission endpoint, although submit responses include it. Project student-detail responses include their submission ID. Frontend consumption and migration are not verified. Attachment access currently checks mentorship ownership or enrollment without a publication-status condition; draft visibility requires a decision.
- `ImageStorageService` writes/deletes now share `app.upload.base-dir` with MVC. URLs and the default `uploads` root are unchanged. Deployments already using a non-default root must migrate existing images previously written under `uploads/`; migration is not performed here.
- The generic MVC exception handler currently reports an unauthorized typed retrieval as 409; the ownership probe checks denial, not a 403 error contract.
- The earlier pre-correction `UploadsServingProbeTest` wrote and deleted its fixed fixture in repository `uploads/student/`. Its prior existence cannot be established from the retained evidence. Current security probes use fresh temporary roots; other application-context tests still initialize their configured `target/test-uploads` directory.
